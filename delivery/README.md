# Delivery

Skills for client delivery work, organized by discipline:

- `salesforce-development/` - Apex, LWC, triggers, flows, metadata, deployments
- `data-management/` - data modeling, migration, cleansing, dedup, ETL, data quality
- `project-management/` - planning, status reporting, scope control, risk, PMO tooling
- `salesforce-consulting/` - solution design, requirements, business analysis, advisory
- `quality-assurance/` - test strategy, test design, UAT, regression, QA automation
- `integrations/` - APIs, MuleSoft/middleware, external systems, auth, integration patterns

Put each skill under the discipline that owns the task, in its own folder with a
`SKILL.md` (see the root README).
