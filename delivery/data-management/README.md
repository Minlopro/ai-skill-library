# Delivery / Data Management

Skills for data work: data modeling, migration and loads, cleansing and
deduplication, ETL, and ongoing data-quality checks.

## Skills

- **data-migration-runbook** — plan and run a Salesforce migration/transformation the safe, repeatable way: profile, map, transform, load, validate, reconcile; external IDs/upsert, load order, dedup, rollback, and the client-data handling rule (transact non-PHI, never store; PHI gets extra scrutiny).
